## 📖 What is Habit Now?

**Habit Now** is an open-source **habit tracker app built with Flutter and Dart**. It combines a **habit tracker**, a **task manager (to-do list)**, a **recurring task planner** and a **built-in timer** in one productivity app, so you can build daily routines, stay consistent and see how long you actually spend on each task.

It uses the **Bloc pattern** for clean, predictable state management and **Hive**, a fast NoSQL database, to keep all your data **locally on your device (offline-first)**.

If you are looking for a **Flutter habit tracker example**, a **Flutter to-do app with Bloc and Hive**, or a **productivity app source code** to learn from or build on, this project is for you.

## ✨ Features

| Feature | Description |
| --- | --- |
| ✅ **Habit tracking** | Create habits and build daily routines you can stick to |
| 📝 **Task management** | Add, organize and complete one-off tasks in a simple to-do list |
| 🔁 **Recurring tasks** | Schedule repeating tasks so your routines run on autopilot |
| ⏱️ **Built-in focus timer** | Time every task and habit session to track real effort and duration |
| 🧱 **Bloc state management** | Predictable, testable and scalable app state with the Bloc pattern |
| 💾 **Hive local database** | Fast NoSQL storage that works fully offline, no account or internet needed |

## 🚀 Getting Started

Run the Habit Now Flutter app locally in four steps.

**Prerequisites:** [Flutter SDK](https://docs.flutter.dev/get-started/install) installed and an emulator or physical device connected.

1. **Clone the repository**

   ```bash
   git clone https://github.com/Kind-Unes/HabitNow.git
   ```

2. **Open the project folder**

   ```bash
   cd HabitNow
   ```

3. **Install dependencies**

   ```bash
   flutter pub get
   ```

4. **Run the app**

   ```bash
   flutter run
   ```
